# Third-party design and fonts

## Monica by StyleShout

The portfolio presentation is adapted from the Monica 1.0.0 template by StyleShout, rebuilt as Next.js components with custom portfolio content and existing application functionality.

Original template: https://styleshout.com/free-templates/monica/
License terms: https://styleshout.com/template-license/

The template permits modification and use in personal and commercial projects with a visible attribution link to StyleShout. That attribution is included in the portfolio footer. The original template archive is not redistributed in this repository. Demo photographs, identities, example testimonials, and newsletter integrations are not included.
